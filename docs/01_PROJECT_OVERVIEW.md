# FitTrack - Project Overview

FitTrack is a premium client-side health and fitness dashboard app built with React 19, Tailwind CSS v4, and Lucide icons. 

## Core Purpose
The application serves as a comprehensive portal to track cardiovascular and strength progression. It provides an intuitive, distraction-free environment for users to log daily nutrition, hydrations, sleep quality, and active workout schedules. 

## High-Level Capabilities
- **Kinetic Glass Aesthetic:** Full screen glassmorphism, responsive drawers, floating tab bars, and rich depth layout styling.
- **Biometric Integration:** Heart rate drift simulation, dynamic calorie burn calculations, and step counting updates.
- **Unified Global State Engine:** Bound using standard React Context, enabling immediate cross-tab synchronization.
- **Resilient Offline Cache:** Seamless automatic serialization to browser cache with complete exception safety.
